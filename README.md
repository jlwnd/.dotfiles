# .Dotfiles

My personal configuration files managed with **GNU Stow**.

## 🚀 Quick Install

Run this command to automatically install dependencies, clone the repo, and set up symlinks. It is safe to run multiple times.

```bash
curl -fsSL https://raw.githubusercontent.com/jlwnd/.dotfiles/main/install.sh | bash
```
*(You can append `--clean` to the command above to do a fully fresh install: `.../install.sh | bash -s -- --clean`)*

## 🛠️ Requirements

You need `neovim`, `stow`, and a Nerd Font installed.
